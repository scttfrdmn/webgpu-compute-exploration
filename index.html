WebGPU Compute Exploration

Twenty-three interactive examples of GPU computing with WebGPU compute shaders written in WGSL, from basic parallel operations to real-time physics simulations and ray-marched fractals. Each interactive example is set up as you scroll to it and runs when you press Start.

12Falling Sand

Sand, water, oil, fire, plants and acid on a 320×240 grid. Every step, one GPU thread per 2×2 block moves and reacts its four cells (the Margolus neighborhood), so grains never collide.

6 3

Algorithms & signal processing

14FFT Audio Visualizer

A real-time spectrum analyzer: the Web Audio API supplies raw samples, and the GPU applies a Hann window, runs a radix-2 Cooley-Tukey FFT (one compute dispatch per stage), converts to dB, keeps a scrolling spectrogram and detects beats.

0.60 90 dB
Presets

Audio: the synth demo needs no permissions and plays quietly (Mute silences the speakers, not the analysis). The microphone is requested only when you press Microphone and is never played back. Files are decoded locally and loop. The disc in the corner flashes on detected beats.

15Parallel Sorting

Bitonic sort and LSD radix sort on the GPU. The benchmark sorts up to 4 million keys, checks the result against the CPU's sort and compares timings; the bar chart animates bitonic sort one compare-exchange stage at a time.

8

Reading the chart: background blue/purple marks blocks of size k that sort up/down in the next stage; the strip below pairs each orange bar with the cyan bar j places to its right. Gray bars are padding up to a power of two.

16K-Means Clustering

Lloyd's algorithm on up to 500,000 points: each iteration one compute pass assigns every point to its nearest centroid and a two-level workgroup reduction moves each centroid to the mean of its points. Watch the centroids travel, with trails, until no point changes cluster.

5 100k 5 5% 5

Controls: Start iterates until no point changes cluster, Step runs one iteration, Reset picks new initial centroids for the same points, Regenerate draws a new point cloud. Changing K re-initializes; changing the data sliders regenerates.

17Voronoi (Jump Flooding)

The Jump Flooding Algorithm builds a Voronoi diagram and distance field for up to 1024 seeds on a 1024×768 grid in about log2(1024) = 10 compute passes, under Euclidean, Manhattan or Chebyshev distance.

64
Layouts

Interaction: click to add a seed · drag a seed to move it · right-click or shift-click to remove the nearest seed. Animate lets the seeds drift and recomputes the diagram every frame; Exact check counts the pixels where JFA differs from brute force.

18Maze Generation & Solving

Mazes of up to 1023×767 cells are carved on the CPU, because the recursive backtracker, Kruskal's and Prim's algorithms each depend on every earlier step. A GPU then solves them with a breadth-first wavefront: one compute dispatch per distance level, one thread per cell. The flood is colored by distance, and the shortest path is traced back from the goal.

16
0%

Interaction: click to move the start (green), shift-click or right-click to move the goal (red). Loops removes a share of the walls so there are several routes and BFS has to pick the shortest; Generate builds a new maze with the selected algorithm and size.
